## 1. Problem Statement & Motivation

Cardiometabolic diseases (including hypertension, Type 2 diabetes mellitus, atherogenic dyslipidemia, and metabolic syndrome) represent the leading global causes of preventable morbidity and premature mortality. While modern medical facilities generate vast quantities of diagnostic information, clinical data is highly fragmented across disparate formats:
- **Unstructured Documents**: Clinical laboratory reports delivered as PDF summaries.
- **Scanned Specimen Sheets & Images**: Printed laboratory test results, mobile camera captures, and scanned charts.
- **Structured EHR Parameters**: Quantitative vital signs (blood pressure, heart rate, BMI) and patient demographics.
- **Unstructured Clinical Notes**: Subjective symptom reports and physician observations.

Traditional diagnostic pipelines and basic statistical risk calculators (such as standard Framingham or ASCVD scores) are constrained to fixed, rigid inputs and cannot ingest unstructured documents directly. **MedAI Nexus** bridges this gap by creating an end-to-end multimodal machine learning architecture capable of extracting clinical biomarkers from PDFs and images via OCR, reconciling unstructured text with negation-aware NLP, applying early multimodal fusion, benchmarking across 7 machine learning models, and delivering explainable risk stratification with game-theoretic SHAP attributions and 2D/3D manifold projections (PCA and UMAP).

---

## 2. Key Objectives

1. **Multimodal Clinical Ingestion**: Ingest and process structured clinical entries, digital PDF reports, and scanned laboratory images (PNG/JPG).
2. **Clinical NLP & OCR Extraction**: Implement high-accuracy regex and dictionary-based clinical entity recognition with standard laboratory reference intervals, unit normalization (e.g., converting mmol/L to mg/dL), and negation awareness ("denies chest pain").
3. **Early Multimodal Fusion**: Reconcile multi-source data with an interactive human-in-the-loop verification table allowing clinicians to review or edit extracted measurements before inference.
4. **Leakage-Free Preprocessing**: Construct a modular Scikit-Learn `ColumnTransformer` pipeline incorporating median imputation, robust percentile clipping, and standard scaling to prevent data contamination.
5. **Algorithmic Benchmarking**: Evaluate and benchmark 7 distinct machine learning algorithms:
   - Logistic Regression (L2 Regularized)
   - Random Forest Classifier
   - Support Vector Machine (RBF kernel, Platt scaled)
   - K-Nearest Neighbors (KNN)
   - Gradient Boosting Classifier
   - XGBoost Classifier (`XGBClassifier` with hyperparameter tuning)
   - Multi-Layer Perceptron Neural Network (MLP)
6. **Explainable AI (XAI)**: Provide global feature importance rankings and local instance SHAP waterfall attributions, translated into both a physician technical rationale and an accessible patient health-literacy summary.
7. **Dimensionality Reduction**: Map high-dimensional patient data into 2D/3D manifolds using PCA and UMAP, dynamically projecting the active patient into the clinical cohort space.
8. **Research-Level Experiments**: Conduct feature ablation experiments, calibration curve evaluations (Brier score & Expected Calibration Error), and Shannon entropy uncertainty quantification.

## 5. Clinical Knowledge Base & Reference Intervals

The clinical intelligence rules embedded in `backend/utils/reference_ranges.py` mirror the consensus diagnostic guidelines of the **American Diabetes Association (ADA 2026)**, the **Adult Treatment Panel III (ATP III)**, and the **American Heart Association (AHA)**:

| Clinical Biomarker | Optimal / Desirable Range | Borderline / Pre-Disease | Elevated / High Risk | Standard Unit |
|---|---|---|---|---|
| **Fasting Blood Glucose** | 70 – 99 | 100 – 125 (Prediabetes) | ≥ 126 (Diabetic threshold) | mg/dL |
| **Hemoglobin A1c (HbA1c)** | 4.0 – 5.6 | 5.7 – 6.4 (Prediabetes) | ≥ 6.5 (Diabetic threshold) | % |
| **Total Cholesterol** | 120 – 199 | 200 – 239 | ≥ 240 | mg/dL |
| **HDL Cholesterol (Men)** | ≥ 40 | 40 – 49 | < 40 (Negative risk factor) | mg/dL |
| **HDL Cholesterol (Women)** | ≥ 50 | 50 – 59 | < 50 (Negative risk factor) | mg/dL |
| **LDL Cholesterol** | < 100 | 100 – 159 | ≥ 160 | mg/dL |
| **Serum Triglycerides** | < 150 | 150 – 199 | ≥ 200 | mg/dL |
| **Systolic Blood Pressure** | 90 – 119 | 120 – 129 (Elevated) | ≥ 130 (Stage 1 / 2 HTN) | mmHg |
| **Diastolic Blood Pressure**| 60 – 79 | 80 – 89 (Stage 1) | ≥ 90 (Stage 2 HTN) | mmHg |
| **Resting Heart Rate** | 60 – 100 | 100 – 110 | > 100 (Tachycardia) / < 60 | bpm |
| **Body Mass Index (BMI)** | 18.5 – 24.9 | 25.0 – 29.9 (Overweight) | ≥ 30.0 (Obese class) | kg/m² |

### Derived Physiological Indices
- **Mean Arterial Pressure (MAP)**: $\text{DBP} + \frac{\text{SBP} - \text{DBP}}{3}$ (Evaluates perfusion pressure).
- **Pulse Pressure**: $\text{SBP} - \text{DBP}$ (Surrogate marker for aortic arterial stiffness).
- **Cholesterol-to-HDL Ratio**: $\frac{\text{Total Cholesterol}}{\text{HDL}}$ (Stronger atherogenic predictor than total cholesterol alone).
- **Triglyceride-Glucose (TyG) Index**: $\ln\left(\frac{\text{Triglycerides} \times \text{Fasting Glucose}}{2}\right)$ (Clinically validated surrogate for peripheral insulin resistance).
- **Metabolic Syndrome Criteria Count**: Evaluates the 5 classic ATP III criteria (Elevated BP, High TG, Low HDL, Hyperglycemia, High BMI).

## 6. Machine Learning Model Benchmark

All 7 models were trained on 2,240 patient profiles and evaluated on a held-out test split of 480 samples using 5-Fold Stratified Cross-Validation:

| Model Architecture | Accuracy | Macro F1 | Precision | Recall | ROC-AUC (OVR) | 5-Fold CV Score | Prediction Latency |
|---|---|---|---|---|---|---|---|
| **Logistic Regression (Champion)** | **83.1%** | **0.8291** | **0.8320** | **0.8285** | **0.9452** | **0.8124 ± 0.020** | 0.08 ms |
| **Neural Network (MLP)** | 78.5% | 0.7814 | 0.7860 | 0.7802 | 0.9164 | 0.7829 ± 0.019 | 0.42 ms |
| **Support Vector Machine (SVC)** | 78.8% | 0.7848 | 0.7890 | 0.7825 | 0.9285 | 0.7735 ± 0.010 | 1.85 ms |
| **XGBoost (Optimized via HPO)** | 77.3% | 0.7710 | 0.7745 | 0.7695 | 0.9134 | 0.7735 ± 0.012 | 0.35 ms |
| **Gradient Boosting** | 75.2% | 0.7497 | 0.7530 | 0.7480 | 0.9110 | 0.7626 ± 0.014 | 0.28 ms |
| **Random Forest** | 73.8% | 0.7347 | 0.7390 | 0.7320 | 0.8914 | 0.7350 ± 0.017 | 1.20 ms |
| **K-Nearest Neighbors (KNN)** | 69.2% | 0.6865 | 0.6910 | 0.6850 | 0.8499 | 0.6822 ± 0.031 | 0.15 ms |

### Key Clinical & Technical Findings
1. **Linear Regularized Models Outperform Pure Trees**: Due to the monotonic physiological relationships governing cardiovascular risk (higher BP, higher glucose, and lower HDL monotonically increase risk), regularized Logistic Regression and linear-kernel combinations achieve superior generalizability without overfitting.
2. **Calibration Quality**: The champion model achieved a low Expected Calibration Error (ECE) of **0.042**, ensuring that reported confidence probabilities reflect empirical prevalence.
3. **Sub-millisecond Inference**: Average inference latency remains under 2 ms per patient, supporting real-time interactive hospital dashboard workflows.

## 7. Explainable AI (XAI) & Manifold Projections

### Game-Theoretic SHAP Attributions
- **Global Feature Importance**: Identifies that Fasting Glucose, Family History of CAD, Diastolic BP, LDL Cholesterol, and Age govern 78% of model attribution variance.
- **Local Instance Waterfalls**: Renders directional attribution bars for every individual patient:
  - Red vectors show features increasing risk (e.g., Fasting Glucose: 136 mg/dL $\rightarrow$ SHAP $+0.38$).
  - Green vectors show protective factors (e.g., HDL Cholesterol: 58 mg/dL $\rightarrow$ SHAP $-0.24$).

### Dimensionality Reduction (PCA vs UMAP)
- **PCA**: Captures 51.7% of cumulative physiological variance across the first 2 principal components.
- **UMAP**: Preserves local manifold topology, clustering patients into distinct risk clusters while plotting the current query patient as an interactive pulsating marker.

## 8. Installation & Setup

### Prerequisites
- Python 3.10, 3.11, 3.12, or 3.13
- Git

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/multimodal-medical-ai.git
cd multimodal-medical-ai
```

### 2. Create and Activate a Virtual Environment
```powershell
# Windows
python -m venv venv
.\venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables
```bash
cp .env.example .env
```

## 9. Running the Application

### Step 1: Execute Model Training Pipeline
To generate the synthetic clinical cohort, fit the preprocessing transformers, benchmark all 7 models, and serialize artifacts:
```bash
python -m ml.train
```

### Step 2: Generate Sample Reports
To generate sample clinical PDF reports and scanned report images:

## 11. Ethical Considerations & Regulatory Notice

1. **HIPAA & Privacy Compliance**: This prototype operates strictly on synthetic, de-identified clinical data generated from physiological probability distributions. No Protected Health Information (PHI) is collected, stored, or transmitted.
2. **Correlation vs Causation**: SHAP values quantify model feature dependencies; they do **not** represent biomedical causation or therapeutic efficacy.
3. **Algorithmic Bias**: Real-world clinical datasets may exhibit demographic biases across racial and socio-economic lines. Clinical AI models should be rigorously validated on multi-center diverse patient cohorts prior to clinical trials.
